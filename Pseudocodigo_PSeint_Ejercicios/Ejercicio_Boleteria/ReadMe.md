##Ejercicio Boleteria en Pseint##



#**Esencia del ejercicio**#



Este ejercicio esta pensado para emular un menú para la compra de boletos de bus y el control de ventas a través de un contador para cada destino disponible.



El Pseudocódigo utiliza recursos como `Repetir`, `Mientras` y `Segun`.



Adicional a lo solicitado en el instructivo, se añadieron funciones adicionales buscando robustez en el programa y previniendo errores comunes del usuario.



#**Módulos**#



Cree un pequeño sistema de módulos.



* Uno es simplemente una pequeña animación. -> (AnimacionCarga)
* El otro es una validación reutilizable para rangos de valores. -> (LeerValidador)



#Instancias a mejorar#



* En un futuro se buscará migrar el Pseudocódigo a un lenguaje formal.
* Se deben añadir mayores barreras para evitar errores de ingreso, como datos de distintos tipos al esperado.
